## 已解决的问题清单

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | history/resume user_id=None | useStream reconnect 不带 context | thread 表 fallback |
| 2 | marketplace tool gating "different loop" | sync wrapper 包 async PG store | 预解析到 metadata |
| 3 | Memory update KeyError 'user' | PG store 返回 {} | 空结构修复 + 三层防御 |
| 4 | Memory 页面 RangeError | formatTimeAgo("") | Invalid Date 防御 |
| 5 | Marketplace skill 安装后不显示 | resolver 忽略纯 DB skill | Step 6 + 前端 Marketplace tab |
| 6 | Marketplace seed 重复插入 | 每次 API 调用触发 insert | merge() + 模块级标志 |
| 7 | 测试数据泄漏到生产 DB | fixture commit 后 rollback 无效 | SAVEPOINT 模式 |
| 8 | dev 账号每次重启丢状态 | 每次注册新 user + 新 org | 固定 ID seed + 自动 install |
| 9 | LangGraph 线程越权 | nginx 只验证身份不验证归属 | `_enforce_thread_ownership()` |
| 10 | Session Cookie 不安全 | 缺 Secure 标志 | 生产环境 secure=True |
| 11 | 注册无防刷 | 无 rate limit | per-IP Redis 计数器 |
| 12 | Thread not found | Gateway 没同步到 LangGraph | create_thread 加 httpx 调 LangGraph |
| 13 | RECURSION_LIMIT | 默认 25 步太低 | 前端 config 设 150 |
| 14 | web_search 不可用 | marketplace tools 未 auto-install | 注册时 install skills + tools |
| 15 | claude-to-deerflow 误导模型 | 生产环境不需要 | 从服务器删除 |
| 16 | 冷启动 36 秒 | graph 首次加载慢 | warmup 脚本 |
| 17 | checkpointer 权限错误 | SQLite + ProtectSystem | 切换 PG checkpointer |
| 18 | 前端 env 变量名不匹配 | GATEWAY_URL vs BACKEND_BASE_URL | 修正 .env.local |
| 19 | present_file 报错 | 全局路径 vs per-user 路径不匹配 | 用 thread_data outputs_path 解析 |
| 20 | artifact 下载 404 | path_utils 不支持 per-user | 加 user_id 参数 + per-user 优先 |
